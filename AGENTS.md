# slicc-browsers

Shared browser data for slicc-cli (Go) and slicc-cdp's playwright-cli (Rust, also wasm32-wasip1): `catalog.json`, `schema/`, and the conformance corpus in `corpus/<case>/` (bundled into `corpus.json` by `npm run corpus`), and the protected-origin vectors `protected.json` with their JS reference `protected.mjs`. Three thin wrappers at one version: the Go module at the root (`sliccbrowsers`), the Rust crate `slicc-browsers` (`src/`), and the npm package. README.md is the spec; keep it in step. No comments in any file except Go directives and `# renovate:` annotations in workflows. No CLAUDE.md. Tests live in `test/integration/` (Go and Rust). `npm run validate`, `npm run lint`, `npm test`, `npm run build` must pass. Never use ports 9222-9229 in the corpus or tests, and fake the process list. Releases come from `main` via semantic-release; never move or delete a pushed tag; if a release fails after tagging, fix forward with the next patch.
